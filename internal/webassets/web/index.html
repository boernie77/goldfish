            Einstellungen

            Wie viele Sekunden der Player im Voraus lädt. Höhere Werte helfen bei langsamer Verbindung, brauchen aber mehr Speicher.

            Minimaler Vorpuffer, bevor die Wiedergabe startet. 0 = sofort spielen. Der Player hält zu Beginn an, bis so viele Sekunden gepuffert sind. Wert wird auf den Haupt-Puffer (oben) gecapt — für höheren Startpuffer erst dort erhöhen.

            Alle wieviele Sekunden ein Vorschau-Thumbnail erzeugt wird. Gilt für neu generierte Trickplay-Daten — bestehende bleiben wie sie sind.

            TMDB-Anreicherung

            Direct Play vs. Transcode

            Direct Play: Originaldatei unverändert streamen. Null CPU-Last, beste Qualität. Nur möglich, wenn Browser + Datei-Codec zueinander passen (z. B. mp4/h264/aac).

            Transcode: Server wandelt das Video live in browser-kompatibles H.264/HLS um. Vorteile: Kompatibilität (AVI/WMV/MKV), geringere Bandbreite (siehe Profile), Audio-Downmix. Nachteil: GPU/CPU-Last.

            Metadaten + Poster stammen von The Movie Database. Dieses Produkt nutzt die TMDB-API, ist aber nicht von TMDB unterstützt oder zertifiziert.
